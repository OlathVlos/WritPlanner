In-game WoW Forever addon for planning Craftsman's Writ runs and Merchant's Favor crates.
Owner: Bill (GitHub OlathVlos). Explain things plainly; he isn't a developer.

## Client facts (WoW Forever)
- `## Interface: 16001`, build 1.60.x, retail-style APIs (C_Item, C_QuestLog, C_Reputation, C_CurrencyInfo, C_AuctionHouse).
- Modern auction house. A full browse (`C_AuctionHouse.SendBrowseQuery` with an empty search, then `RequestMoreBrowseResults`) returns every item with min price and quantity: ~51 pages, ~25k listings, ~23 s.
- `GetRealmName()` returns an empty string, so scans are keyed `Forever-<Faction>`; old `-<Faction>` keys get migrated.
- Writ rep factions: 2586 Azeroth Commerce Authority (Alliance), 2587 Durotar Supply and Logistics (Horde).
- Each named writ can be handed in once per day; duplicate copies wait for later days. Waylaid Crates have no daily limit. Artisan crate Favor (20) is an estimate.

## Files
| File | What it does |
|---|---|
| `WritPlanner.toc` | Load order: Data, Core, Scan, UI. A new file needs a full game restart, not `/reload`. |
| `Data.lua` | Generated by `tools/gen_data.py` from the website's `data.json`: 150 writs (`ns.WRITS`) and 30 Waylaid Crates (`ns.CRATES`). **No prices bundled** in the public build (`ns.SNAPSHOT = nil`). |
| `Core.lua` | Data unpack, saved variables, game-API wrappers (all pcall-guarded), price sources, planner, Road to Exalted, Merchant's Favor, Auctionator lists, waypoints, events. |
| `Scan.lua` | Optional read-only AH price scan (button press only, throttled, pauses while the Sell tab is open). |
| `UI.lua` | Standalone window (not a UIPanel; Esc closes it via UISpecialFrames). Pages: Plan your run, Road to Exalted, Merchant's Favor, Find writs, Shopping list, Settings. Also the minimap button, AH tab-row button, `/writplan`, Addon Compartment. |
| `tools/` | `gen_data.py`, `lint.js` (luaparse syntax/globals check), `test_harness.lua` (full suite with made-up prices), `test_public.lua` (no-price mode, scan, AH button). |

## Rules to keep
- **Blizzard policy:** information only. Never buy, post, turn in, move or click for the player; no protected/secure functions, no `loadstring`/`RunScript`, no obfuscation, no in-game ads or donation prompts.
- **Globals:** only `WritPlannerDB`, `WritPlannerCharDB`, `WritPlannerFrame`, `WritPlannerMinimapButton`, `WritPlannerAHButton`, `SLASH_WRITPLANNER1/2`, `SlashCmdList.WRITPLANNER`, `WritPlanner_OnAddonCompartmentClick`. Everything else goes on the addon table `ns`.
- **Events:** register through `pcall` so a missing event can't throw; bag/quest refreshes are debounced, and the UI only redraws while the window is open.
- **Prices:** auto order is GoldScout (`GoldScoutPricesData`, market key ending `-Horde`/`-Alliance`), then Auctionator API v1, then `TSM_API` dbmarket, then Writ Planner's own scan. A chosen source falls back to the others. With no prices anywhere it runs **rep-only mode**.
- **Licence:** GPL-3.0-or-later. Turn-in data is derived from QuestieDB, credited in `NOTICE.md`. Don't bundle TSM/GoldScout/Gold Capped/Auctionator prices in the repo.
- **Privacy:** no personal details, account names or SavedVariables in the repo (`.gitignore` blocks `WTF/`).

## Checking a change
```
npm i -g luaparse            # once
node tools/lint.js *.lua     # syntax + list of globals written
pip install lupa             # once; then run each suite in a Lua 5.1 runtime:
python3 -c "import lupa.lua51 as m; L=m.LuaRuntime(unpack_returned_tuples=True); L.execute('DIR=\"./\"'); L.execute(open('tools/test_harness.lua').read())"
python3 -c "import lupa.lua51 as m; L=m.LuaRuntime(unpack_returned_tuples=True); L.execute('DIR=\"./\"'); L.execute(open('tools/test_public.lua').read())"
```
Both suites must end with their PASSED lines. Bill likes changes tested, installed into his AddOns folder, then a short plain summary, telling him `/reload` (or a restart for new files) only when everything requested is finished.
